# 📊 Financial Loan Analysis Dashboard

An interactive **Financial Loan Analysis Dashboard built in Microsoft Excel** to analyze loan applications, approval/rejection patterns, customer segments, loan performance, and potential risk areas.

The project transforms financial loan data into an interactive analytical dashboard using **Excel Pivot Tables, charts, KPIs, filters, and data transformation techniques**.

---

## 🎯 Business Problem

Financial institutions need to continuously monitor loan performance to understand:

* Which loan segments have higher risk?
* What patterns can be observed in loan approvals and rejections?
* How are loans distributed across customer income levels?
* Which loan statuses require closer monitoring?
* How can financial data be converted into actionable business insights?

This project addresses these questions through an interactive Excel-based analytical dashboard.

---

## 🚀 Project Objectives

The analysis focuses on:

* 📌 Analyzing loan approval and rejection patterns
* 📌 Identifying potentially high-risk customer segments
* 📌 Tracking loan performance and default-related trends
* 📌 Understanding customer income and loan distribution
* 📌 Exploring loan status patterns over time
* 📌 Creating an interactive dashboard for business analysis
* 📌 Presenting financial insights through clear visualizations

## 📈 Dashboard Analysis

The dashboard provides an interactive view of loan-related performance and customer characteristics.

### 1. Loan Approval & Rejection Analysis

Analyzes patterns across loan statuses to understand:

* Approved vs. rejected applications
* Distribution of loan outcomes
* Patterns across different customer segments

### 2. Risk Analysis

Explores segments associated with potentially higher loan risk, helping identify areas that may require additional monitoring.

### 3. Customer & Income Analysis

Analyzes:

* Customer income distribution
* Loan amount distribution
* Relationship between customer characteristics and loan outcomes

### 4. Loan Performance

Tracks loan-status trends to understand overall portfolio behavior and identify areas requiring attention.

### 5. Interactive Dashboard

Users can explore the analysis using interactive filters and dashboard visuals instead of manually analyzing individual records.
